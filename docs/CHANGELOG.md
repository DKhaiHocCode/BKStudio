### Tính năng
- 2026-10-29 · T-023: máy trạng thái đơn (`order/state`) — `OrderStateMachine.transition(orderId, action, expectedVersion, actor[, Details])` là nơi duy nhất đổi trạng thái: kiểm `version` trước (sai → `VERSION_CONFLICT` 409), tra bảng chuyển hợp lệ 17 cạnh cho 2 loại đơn (sai → `INVALID_TRANSITION` 409), `UPDATE … WHERE version = ?`, ghi `audit_log` (`ORDER_TRANSITION`, chỉ trạng thái) và 1 dòng `email_outbox` (`dedupe_key = order:{id}:{ACTION}:{version mới}`, payload chỉ `publicCode` + `status`) trong cùng transaction. SHIP bắt buộc mã vận đơn (≤100 ký tự, không ký tự điều khiển) và set `shipped_at`; COMPLETE set `completed_at`; huỷ/forfeit lưu `cancel_reason` (≤500). `AuditLogWriter.by(actor, …)` thêm cho ADMIN/SYSTEM/CUSTOMER (ADMIN ghi `actor_id`). Chưa có endpoint, chưa nhả kho/slot. Surefire 142 + Failsafe 616 xanh.

Biến môi trường mới `APP_BASE_URL` (prod bắt buộc https). Chưa ghi email outbox (T-024). Surefire 139 + Failsafe 594 xanh.
